4# Sprint 3 — Protein–Protein Interaction (PPI) Network Analysis

## Objective
Construct a protein–protein interaction (PPI) network using STRING to identify functional interactions among significantly differentially expressed genes.

## Input
- 139 mapped Mus musculus gene symbols

## Network Statistics

- Nodes: 133
- Edges: 141
- Expected edges: 56
- Average node degree: 2.12
- Average clustering coefficient: 0.294
- PPI enrichment p-value: < 1e-16

## Biological Interpretation

The interaction network contained significantly more interactions than expected by chance, indicating that the differentially expressed genes are biologically connected and participate in common cellular pathways.
